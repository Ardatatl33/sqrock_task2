# Student Performance Predictor

A beginner-friendly regression project that explores how academic factors relate to student final marks. The notebook follows the six project stages from data collection through model evaluation.

> **Dataset limitation:** This project uses synthetic data. Its charts and model scores demonstrate the workflow only; they are not validated results for real students and should not be used to make decisions about students.

## Dataset

The reproducible CSV contains 300 synthetic records and these columns:

- `Study Hours`
- `Attendance`
- `Previous Score`
- `Assignments Score`
- `Final Marks` — prediction target

The dataset is generated by `scripts/generate_data.ps1`. Some input values are intentionally missing so the preprocessing workflow can demonstrate missing-value handling.

## Development Process

1. **Data collection:** Created a reproducible synthetic CSV with the required academic features.
2. **Data preprocessing:** Inspected data types and missing values; split the data into 80% training and 20% test sets; calculated input medians from the training set only and applied them to both sets. `Final Marks` was kept out of the input features. No categorical columns were present, so encoding was not needed. Scaling was not applied because it was not required for these regressors.
3. **Exploratory data analysis:** Compared study hours and attendance with final marks, reviewed the score distribution, and created scatter, histogram, and bar charts.
4. **Model building:** Defined Linear Regression, Decision Tree Regressor, and Random Forest Regressor models.
5. **Training and testing:** Fit each model on training data, predicted marks for the unseen test features, and compared predictions with actual marks.
6. **Evaluation:** Compared models using MAE, MSE, and R².

## Test Results

| Model | MAE ↓ | MSE ↓ | R² ↑ |
|---|---:|---:|---:|
| Linear Regression | 5.02 | 35.55 | 0.85 |
| Random Forest | 5.92 | 53.65 | 0.77 |
| Decision Tree | 7.30 | 81.37 | 0.65 |

On this particular synthetic train/test split, Linear Regression had the lowest MAE and MSE and the highest R². These scores describe only this synthetic dataset and split.

## Run Locally

1. Clone the repository and open its folder:

   ```powershell
   git clone https://github.com/Ardatatl33/sqrock_task2.git
   cd sqrock_task2
   ```

2. Install the notebook dependencies:

   ```powershell
   pip install pandas scikit-learn matplotlib jupyter
   ```

3. Start the notebook:

   ```powershell
   jupyter notebook student_performance_predictor.ipynb
   ```

To regenerate the synthetic CSV from PowerShell, run:

```powershell
.\scripts\generate_data.ps1
```
